- AGENTS/스킬 변경 경로·범위 / 원본 참조 / 적용 방법:
- 결정 사항 / 결과 / 실행한 검증과 남은 검증:

## 다른 기기 적용 순서

로컬 원격 식별 확인 → 변경 보존 → fetch 및 목표 SHA 검증 → 가능한 fast-forward → 지침 반영 → 다음 작업.

기록만으로 복원 불가능한 항목과 추가로 필요한 원본을 명시한다.
